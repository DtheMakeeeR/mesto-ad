# Mesto

Mesto — это веб-приложение, где пользователи могут делиться фотографиями, ставить лайки и редактировать свой профиль.

## Ссылка на проект
https://dthemakeeer.github.io/mesto-production/

## Технологии

- HTML
- CSS (БЭМ — блочная организация стилей)
- JavaScript (ECMAScript Modules)
- Vite
- Fetch API
- GitHub Pages
- GitHub Actions (CI/CD)

## Установка и запуск

```bash
npm install        # Устанавливает все зависимости из package.json
npm run dev        # Запускает локальный сервер для разработки с горячей перезагрузкой
npm run build      # Собирает проект в папку dist
npm run deploy     # Публикует содержимое dist на GitHub Pages
```

## Возможности проекта

### Работа с профилем
- **Загрузка данных профиля** — при открытии страницы имя, описание и аватар пользователя автоматически загружаются с сервера и 
  отображаются в интерфейсе.
- **Редактирование профиля** — изменение имени и описания пользователя через модальное окно; данные отправляются на сервер методом 
  `PATCH`, после чего страница обновляется без перезагрузки.
- **Обновление аватара** — смена аватарки по URL-ссылке; после отправки формы аватар обновляется на странице и сохраняется на сервере.

### Работа с карточками
- **Загрузка карточек** — все карточки (фотографии мест) подгружаются с сервера при загрузке страницы и отображаются в виде сетки.
- **Добавление новой карточки** — пользователь может добавить свою карточку, указав название и ссылку на изображение; карточка появляется 
  в начале списка.
- **Удаление карточки** — удаляются только собственные карточки; перед удалением появляется модальное окно подтверждения.
- **Просмотр фотографии в полном размере** — клик по изображению карточки открывает модальное окно с увеличенной версией фото и подписью.

### Взаимодействие с карточками
- **Лайки** — возможность поставить или снять лайк; счётчик лайков обновляется мгновенно, данные отправляются на сервер.
- **Статистика карточки** — по клику на кнопку `i` открывается модальное окно с подробной информацией: название, автор, дата создания, 
  количество лайков и список пользователей, которые лайкнули карточку.

### Модальные окна
- **Открытие и закрытие** — все модальные окна открываются по нажатию соответствующих кнопок и закрываются:
  - по клику на крестик;
  - по клику на оверлей (затемнённую область вокруг окна);
  - по нажатию клавиши `Esc`.
- **Анимация** — плавное появление и исчезновение модальных окон с помощью CSS-переходов.

### Валидация форм
- **Проверка в реальном времени** — все формы (редактирование профиля, добавление карточки, обновление аватара) валидируются по мере 
  ввода.
- **Кастомные сообщения об ошибках** — для поля имени используется специальное сообщение о допустимых символах (буквы, дефис, пробел); 
  для остальных полей — стандартные сообщения браузера.
- **Блокировка кнопки отправки** — пока форма содержит ошибки или пустые обязательные поля, кнопка «Сохранить» / «Создать» неактивна и 
  имеет стиль отключённого состояния.
